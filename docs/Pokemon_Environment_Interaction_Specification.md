# Destructible and interactive Pokémon environments

Research extension · November 13, 2026

## Executive synthesis

Build the first competitive version around **three reusable physical operations**. Replace a component’s state, move a component between validated poses, and switch a local surface or hazard field. Run all three through the same guarded transition system. These operations cover damaged and broken props, felled trees, displaced boulders, cracked ice, steam pulses, and temporary barriers. An empty socket and an occupied socket are two states of the same placement contract. The existing geometry generators can produce the small set of shapes needed to prototype these interactions.

Start with **breakable secondary cover, one breakable optional passage, and one directed fall that creates cover**. The first changes an existing fight. The second creates a rotation decision. The third turns one shape into another with a visible spatial consequence. A local surface switch is the next extension, with brittle ice and a bounded steam pulse as test cases. Whole-map fracture, free terrain excavation, flood simulation, and propagating wildfire require substantially more state, geometry, and testing. Reserve them for settings or modes where those mechanics define the experience.

Give moves explicit environmental effects such as cut, crush, push, heat, chill, and grow. Let each target’s construction, material, scale, and context determine the response. *Legends: Z-A* already distinguishes obstacles that respond to slashing, crushing, or burning and features ice and web obstructions that can become crossings. *Pokopia* supports object pushing, rock breaking, soil tilling, and habitat growth in a building game. Those mechanics support the capability model. Competitive thresholds, duration, and access are original design decisions. [PE04](https://www.serebii.net/legendsz-a/overworldobstacles.shtml) · [PE05](https://bulbapedia.bulbagarden.net/wiki/Obstruction) · [PE06](https://www.serebii.net/pokemonpokopia/abilities.shtml) · [PE08](https://www.nintendo.com/en-ca/whatsnew/get-the-most-out-of-pokemon-pokopia-with-these-helpful-tips/)

The decisive check is whether teams can **reach, contest, and leave each essential objective in every reachable state**. Preserve two independently viable baseline approaches per side under the original default policy. Keep their supports, recovery, and enough permanent sightline breaks to preserve distinct approaches. A shortcut can stay optional for navigation and still invalidate a map if it grants a firing angle that controls both entrances. Validate routes, exposure, and occupied transitions on realized geometry.

This extension uses the existing 35 archetypes, 87 component IDs, R01–R33 grammar, F01–F09 gameplay contracts, and PBL01–PBL12 checks. The companion **Pokemon_Environment_Interaction_Matrices.xlsx** contains the complete component and move matrices, state models, and a profile for every habitat archetype. The recommendation and examples are design specifications. They have documentary and paper-design verification, with collision, performance, and competitive playtests still to run.

## Evidence and scope

The original taxonomy establishes where a physical form occurs. This extension asks what can change in play. A row can have observed geometry, a canonical precedent for a related action, and a proposed shooter response. For example, Icefall Cave supports brittle ice that gives way to a lower floor. A lake sheet that cracks under a move, exposes hazardous water, and reforms only when clear is a new adaptation. [PE11](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_FireRed_and_LeafGreen/Part_18)

| Evidence label | What it supports |
|---|---|
| Canon-supported | A named move, environmental mechanism, or in-world description in a specified title or medium. The register distinguishes observed game mechanics from Pokédex lore and anime. |
| Inferred | A documented action or physical structure supports a related behavior at a different scale, on a different material, or in a different setting. |
| Proposed | Shooter-specific placement, thresholds, cooldowns, geometry, state rules, and multiplayer behavior. A close precedent may accompany a proposed response. |

The evidence is a targeted source review across mainline field moves, *Legends: Z-A*, *Pokopia*, *UNITE*, and exceptional settings already in the baseline. Developer documentation and patches establish what comparison games implemented or attempted to address. They give limited evidence about player outcomes. Patch-era values are historical examples. This is an extension to the habitat audit, with the full franchise geography retained in the original files.

## B. Reusable interaction taxonomy

Use capability flags for authoring and reporting. Use three operations for physical output. A component can support several flags, and several flags can lead to the same output.

| Capability | Meaning and smallest useful implementation |
|---|---|
| Static | Fixed support, occluder, geometry, or rule. Optional chip effects can use the existing shape and masks. |
| Damageable | Accepts a target-specific integrity change. A damaged cue can retain the exact intact collision. |
| Destructible | Replaces or removes a certified shape at a threshold. A broken state may contain a single certified stump, rubble shape, or aperture. |
| Movable | Changes the pose of the same component within a declared area. A discrete socket pair handles first-pass pushes, slides, pivots, and rolls. |
| Deformable | Changes the geometry profile. Use two or three authored/generated shapes for thin material, snowbanks, or a designated loose ground patch before continuous deformation. |
| Transformable | Changes medium, traction, visibility, hazard, or material. Structural freezing also installs a supported shape. |
| Constructible or restorable | Activates, replaces, or reinstates a shape or field in a legal socket. Recovery uses the same swept occupancy and dependency checks as construction. |
| Reactive | Queues a named secondary transition. The secondary action has its own warning, footprint, and budget. |

| Physical operation | Families it covers | When additional machinery earns its cost |
|---|---|---|
| **Replace state or shape** | Intact/cracked/broken, removable debris, opened breach, short wall, frozen support, preset deformed ground, installed or restored barrier. | Add segmented components when players can choose meaningful aperture size or height. Continuous excavation needs a geometry and validation system of its own. |
| **Change pose** | Boulders, logs, gates, pendants, treefall, pivoting columns, and suspended crystals. Use approved destinations and transition sweeps. | Add short server-simulated motion if momentum, chaining, or exact landing is essential to the decision and a fixed trajectory cannot express it. |
| **Switch local field** | Ice traction, mud, concealment, charge, heat, steam, tide/current zones, and growth conditions. | Add field transport only when evolving flow or propagation is central to the mode. Bounded state masks cover most competitive designs. |

One shared transition handler applies integrity, triggers, timing, recovery, and combined outputs. E.g., a felling transition changes A06 pose, leaves an A08 cover proxy, and updates F02 in one transaction. A lake thaw removes support, enables water contact, and updates F07/F08 together. A staged ruin is a finite support graph of named child states. Gameplay rubble and cosmetic fragments have separate collision policies.

**Effect resolution.** A move defines delivered action, strength, area or direction, time profile, environment targeting, and a budget. A target defines resistance/thresholds, geometry and material, attachment, wetness or charge, allowed actions, and role protection. A transition checks actual contact, target profile, and location before committing. Combat damage, type matchups, and structure effectiveness have separate tuning. An explicit projectile might have an environmental impact budget of one target per hit, whereas a designated shockwave may affect several within a declared cap. Consolidate multi-hit events by ability instance and target where appropriate. Keep structure work independent of hero critical hits, damage buffs, DoT tick frequency, or encounter scaling unless deliberately tuned for that move.

## C. Environmental state-transition grammar

Each state defines **presentation, support, movement collision, projectile response, vision, mantle/climb behavior, exposure volumes, and route contributions**. It also declares whether it can be entered with an actor present. Hit decals, scratches and dust can change within a state. A collision-changing crack or a new ballistic aperture is a new gameplay state. Treat opaque, shoot-through brush as concealment. Use audible and geometric cues that communicate imminent failure and safe exits without relying on color alone.

| Model | States and triggers | Geometry, gameplay and recovery |
|---|---|---|
| ST01 Fixed | Fixed, with optional visual reactions | Fixed support, blockers and field bindings. No object integrity required. |
| ST02 Breakable cover | Intact → damaged → failed at integrity thresholds | Damage can use material or VFX. Failed swaps to a lower stable proxy or clears it. Recovery can reset at a round boundary. |
| ST03 Breach insert | Sealed → visibly weakened → open after threshold or public release | Change a local collider, aperture and optional passage. The breach stays open for the round by default. Edge direction is a separate rule. Restore at a cleared phase or round if the mode declares it. |
| ST04 Fall or pivot | Upright → warned → moving → settled, with an optional debris stage | Preselect supported endpoint and reserve sweep. Keep the initial blocking proxy during wind-up. At release use a validated motion mask and bounded hazard if enabled. Install one final rest proxy. |
| ST05 Socket displacement | At A → warned/moving → at B, with an optional safe return | Test start, sweep, and destination for both movement and projectiles. Reject blocked moves before spending an eligible action, or apply declared no-cost retry behavior. |
| ST06 Local field | Inactive or base → warning if harmful → active → dissipating/base | Field profile handles traction, visibility, exposure, or current in a bounded volume. A collision change also invokes a shape or support transition. |
| ST07 Brittle support | Supported → cracked → warned → open liquid or lower landing → optional refreeze/reset | Use a structural insert. Remove support only at the commit tick. Resolve occupants through airborne/medium rules. Recovery adds support only after clearance. |
| ST08 Create or restore | Empty → preview/arming → present → weakened/expiring → empty | Install a finite collider at a valid socket. Require safe placement and expiry under all permitted users. Unoccupied placement gets priority over entombing or teleporting occupants. |
| ST09 Bounded cascade | Stable children → signaled parent failure → declared child states → settled | Apply grouped changes as one transaction when their support must agree. A declared delay produces an explicit intermediate state. Enforce a finite support dependency graph. |
| ST10 Vegetation | Full → cut or burning → cleared/charred → optional regrowth | Swap patch density and concealment. A burning patch can accept suppression before it consumes the cover. Reserve growth envelope and cap heat duration. |
| ST11 Preset surface deformation | Profile A → warned if required → profile B → optional reset | Swap a local depression, drift, or dent with bounded slope and edge geometry. A material-only footprint can reuse ST06. |
| ST12 Alternate route field | State A → visible warning → state B → optional return | Switch a certified water, magnetic, portal or suspension configuration. Bind participant medium, local up and exit policy. |
| ST13 Derived relationship | Base data → recomputed local relation at commit | Support dependencies, concealment edges, passability and threat derive from participating components. They have no independent integrity. |
| ST14 Timed hazard source | Dormant → wind-up → active → cooldown → dormant | Discrete source and exposure volumes. Every pulse has a bounded hazard, duration, affected targets, and recovery route. |

### Transition rules

1. A permitted trigger can come from a hit, impulse, timed effect, nearby movement/load, player use, host field, phase event, or named child failure. Check legal state, cooldown, priority, target roles, cause, and allowed chain budget. Combine threshold work only inside the same object definition.
2. Reserve the target pose, affected surfaces, warning, and spatial sweep. Recheck occupancy and dependencies at commit. Static obstructions block a move. When adding a solid, defer/cancel on occupied volume or use an explicitly certified safe displacement with room to arrive. Never allow a body or objective to be enclosed by a closing insert. A player should be able to read whether the operation was accepted.
3. Apply geometry, support, combat masks, field and edges at a common authoritative revision. For a scripted fall with cosmetic swing, declare exactly when solid cover drops and reappears, and use a clear intermediate collision/hazard policy. If a moving proxy can hit or carry characters, certify its actual sweep and sample it at authoritative simulation ticks. Every shot and body query uses a defined revision.
4. Handle removed support according to the original movement and hazard contracts. A body on breaking ice goes airborne, lands if support exists, and uses hazard contact only after entering liquid. Walk-off or knockback into an exposed void follows the normal fall and knockout rule. Optional player-triggered support loss needs a warning, visible risk and a viable retreat/recovery opportunity. Required ground is never lost to these interactions.
5. Queue secondaries in a predictable order with a cause identifier, target deduplication and depth/area limits. Start with one secondary per trigger group where needed, e.g., a dropped boulder starts a short warning pulse. Environmental cues can portray more debris without additional hits. If a dependency must change together, group it atomically. A loop such as alternating freeze and thaw uses explicit cooldowns and guards.

**Simultaneous events.** Use a documented server order. A useful policy applies scheduled phase resets at a tick boundary, then resolves valid hits against the tick’s environment snapshot, then evaluates transitions. Aggregate same-tick integrity loss, commit at most one lifecycle transition per target, and use a stable cause order for mutually exclusive actions. Define suppress-versus-ignite or melt-versus-freeze by resolved intensity or an explicit priority. Ties should resolve consistently without assigning advantage by connection speed. For a closing gate and an entering actor, occupancy wins and the gate waits or cancels. Preserve state/phase epochs so a late shot or timeout cannot mutate a reset instance.

**Occupied transition policy.** Removal, addition and motion need different guards. For deliberate removal of optional support, communicate the drop and prove an escape or lower recovery state. For an adding solid, refuse or defer while its volume is occupied, including airborne trajectories and occupants below a forming ice sheet. Give each deferral a deadline and a legal fallback such as an already-open aperture until the phase reset. For moving solids, decide whether they carry players, stop on contact, or have a marked swept hazard. Validate the entire chosen behavior. A scheduled reset can change mode phase and state together at a clear staging boundary.

### Persistence and match pacing

| Policy | Best fit | Competitive and operational cost |
|---|---|---|
| Until round or match ends | A breached optional wall, fallen tree, or local rock collapse whose later use is balanced. | Makes scouting and route commitment matter. Accumulated loss of cover can turn late retakes into exposed runs. Test the legal most-altered layouts and both sides of asymmetric modes. |
| Temporary with automatic expiry | Ice chill, steam, smoke, charge, and temporary barriers. | Gives counterplay and cadence. Telegraph expiry and define safe removal when actors stand on the effect. Prevent perma-refresh through overlapping instances. |
| Regrowth or self-repair | Soft foliage or a fictional field in a visibly recovering state. | A reversible local advantage suits repeated fights. Solid recovery needs safe clearance, a clock visible through cues, and a timeout policy that cannot reward body-blocking forever. |
| Player repair or replacement | A counterable barrier in a mode with shared access to the tool. | Creates a choice between combat and rebuilding. Test denial loops, action economy, object economy, and backline abuse. Keep early prototypes focused on round reset. |
| Conditional phase reset | Attack/defense phase change, round swap, moving objective transition, or overtime policy. | Preserves geometry across several fights while avoiding accumulated asymmetry across phases. Reset in a phase buffer or only when volumes are clear. Move the objective only through its own mode logic. |

Prefer permanent-within-round for selected breaches and props, timed fields for reversible combat conditions, and synchronized round/phase reset for solids. Regrowth is an inferred presentation for vegetation with a proposed timer. Solid instant repair mid-fight needs a distinct counterplay reason.

## D. Dynamic gameplay topology rules

Retain the original environment graph, planned gameplay graph, and realized navigation and threat graphs. Attach dynamic changes to the existing F07 edge contract and related F02, F03, F04 and F08 contracts. Each conditional edge declares its direction, endpoint sockets, swept body envelope, permitted states and profiles, traversal time, exposure and counterplay, and the support and hazards it depends on. Every edge has an intended graph role and a geometry-derived result. A state can add a path, remove it, change its cost, or change where shots can cross without changing movement.

| Topology layer | Contract |
|---|---|
| Persistent movement | Stable support and ordinary routes between protected spawn/staging, required checkpoints, objective interaction volumes, and retreat. Include route capacity, turn and body clearance. Spawn vestibules and unavoidable shared endpoint space use the original mode policy. |
| Persistent combat geometry | Keep stable occluders and counter-positions that allow the approaches to work after optional cover is gone. A required tread may remain passable while losing the only screened approach to it. |
| Dynamic movement | Overlay conditional directed edges and state-dependent cost changes. Examples include a breach, a downed-log crossing, traction changes, a broken bridge, or a culvert with changing current. Bind reachability to both clearance and legal occupancy. |
| Dynamic threat | Add or remove lines of sight and projectile travel, assess splash and bounce where supported, and update perch access and approach exposure. Test attack reach from newly opened or constructed positions. |
| Capability overlay | Derive swim, climb, flight, burrow, immunity, and hero-created routes per profile. Access to the map’s essential gameplay comes from the baseline graph. Test how these overlays combine with new hazards and perches. |

For each reachable state, relevant phase and baseline profile, verify that both teams can enter the actual objective interaction volume, use the mode’s control or escort rules, and retreat. Apply the original **two independent viable ingress routes per side** by default. Group shared apertures, common hazard envelopes, and approaches dominated by the same uncontestable firing position. Graph-disjoint paths count separately only when their relevant threat and geometry are independent. Test return directions separately. Count a physically passable lane that forces unavoidable hazard exposure or an unanswerable firing line as failing the relevant baseline approach check. Keep objective scoring, spawn protection, and escort support owned by the mode. F06 anchors are protected from ordinary environmental effects.

| Change | Useful decision | Acceptance test |
|---|---|---|
| Opens a wall | Spend time, attack opportunity or noise to make an offset rotation. | Measure the shortcut from both ends, check the exposed exit, and test rays from the new aperture to spawn, the objective and both baseline approaches. A two-way opening is a useful default. |
| Removes cover | Commit resources to dislodge a defender or prevent retreat from a particular pocket. | In the most exposed reachable state, confirm staged retreat and contest remain available. Check smallest eye/muzzle profile for new slit peeks. |
| Moves or drops cover | Trade one angle for another or choose when to commit to a new crossing. | Check its full sweep, rest collider, shot mask, boosted/mantle heights and knockback landing. Keep travel and retreat envelopes free. |
| Removes optional support | Players choose a risky short route or time denial from nearby. | Check warning, fall, valid lower support or hazard exit, and any actors already standing there. A removed span must leave legal exits for any occupied side. |
| Adds temporary elevation | Creates an angle or short-lived overpass. | Verify what a flier, burrower, smallest body and highest muzzle can now reach. Require a grounded response or clear exposure. Verify expiry with occupants. |
| Adds or changes a hazard | Controls a pocket for a short window and changes optional route cost. | Test the union of overlapping hazards at their timing extremes. No immunity or named move is required to access essential gameplay. |

**Competitive tuning.** Give any breach or cover destruction important to the map a shared access path. For example, certify one common structural attack or slow context action, then allow named moves to do the same job faster or more safely within a payoff cap. Keep universal access outside the destruction requirement itself. With the optional route available, compare teams with and without the specialty under equal spawn timing and target access. An intentional home-side advantage can be tied to phase and side-swapped tests. Check first-contact skew, protected retake angles, time saved after work and recovery, high-ground counters, win/hold time after a change, and how often teams feel forced to draft a specific move. The baseline’s 10–15% neutral contact skew and 20–30% optional travel saving are existing review flags, not proof of balance. New thresholds should be set against roster, mode and map test data.

**Hazard access and physical support.** In the current prototype plan, Water typing or Surf grants safe swimming and lava uses an explicit capability. Keep this rule in the actor’s traversal profile. A break, freeze or flow event changes the affected support, medium or hazard. It does not grant immunity. Incompatible actors can still enter liquids, keep movement control, take time-based maximum-HP exposure damage, and escape via viable banks. A bridge or ice sheet protects them while it provides support above the liquid. Keep hazard entry separate from AI route choice. Use the agreed lethal deadline during continuous exposure, including healing, and actual 3D contact. For a catchable drop, a real lower surface takes the fall. A void crossing or knockback can reach the existing kill boundary. Restrict these to clear optional risk surfaces and test thresholds at body-height extremes.

A dangerous slot declares its footprint, dependencies, exposure, warning, refuge, and disabled fallback. A slot can be skipped if a given seed lacks a valid arrangement. The generator first enforces hard constraints, then ranks candidates by habitat fit, visual communication, distinct decisions, and travel and exposure budgets. **Biome conditions.** A humid jungle permits short scripted wood movement and bounded concealment. Wet fuels can resist heat and permanent roots protect path geometry. A dry scrub patch can burn briefly if the burn area is readable and a stable rotation survives. A volcanic fissure can emit timed steam from an exposed cap set into a fixed lava bed and outlet. A coast or tidal cave binds local gates to approved hydrology states and direction. Ice geometry uses explicit support or traction and a liquid or lower-floor consequence. An ancient wall can breach in its sacrificial bay. A pressure shell or temple foundation needs an authored structural exception. The workbook maps these policies across T01–T35 and records which component and rule IDs drive each proposal.

### Reachability procedure

1. **Build the interaction dependency graph.** Include effects that share a support, moving sweep, recovery volume, ballistic sector, route cut, phase timing, hazard footprint, or trigger. Treat movement abilities and dynamic hazards as dependencies when they enable the same exploit or alter each other’s exits. Edges can connect distant changes through a shared firing position.
2. **Derive the initial state and legal transitions.** Begin from the seed’s approved map and mode phase. Explore the actions players and the environment can take, including both teams acting, simultaneous proposals, repairs, resets, overtime, queued secondaries, and guarded occupancy. Include the timing windows that change warnings, egress or overlap. Coalesce damage states only when collision, threat, affordance, and future transitions are equivalent for the check at hand. Integrity just below a threshold can matter even if shape is identical.
3. **Use conservative bounds before enumerating.** Test a permanent dry/support graph and the union of hazard footprints against it. Treat all optional occluders as absent for a conservative exposure check, then separately test created perches, redirecting obstacles, and occupied transitions. A union or intersection that proves the relevant invariant is sufficient for that invariant. A failure of an over-approximation calls for reachable-state analysis before rejecting the seed. It can represent impossible combinations.
4. **Explore coupled groups exhaustively within a declared budget.** Branch only through legal transitions. Combine independent groups only after proving that their actions commute and their results cannot jointly affect the same invariant. Pairwise testing alone misses three-way cuts or hazard unions. For larger groups use reachability/constraint solving or restrict allowable states until the core invariants can be certified. Use adversarial sampling for additional stress, timing and playtest discovery.
5. **Test both steady states and changeovers.** Derive movement and projectile masks from actual baked shapes, check threat at representative eyes and muzzles, and sweep bodies through motion and recovery. Include mid-slide, late warning entry, simultaneous pushes, trapped guests, bodies between poses, occupied re-freeze, spectator/reconnect, and a moving objective entering the area. Capture the shortest failing action sequence with seed, phase, profiles and changed sockets.

**Worked validation counterexample.** Two permanent dry paths to a lake objective pass navigation checks. A broken crystal removes a lower blind. A fallen tree makes an upper ledge accessible. Each change alone preserves two independent approaches. In combination the ledge sees the lower entrance and the upper landing, and the back angle has no counter-position. That pair fails the original approach policy. A stable rock spur that screens one entrance repairs the failure. If the tree can only fall while the crystal shield is intact and occupancy rules guarantee a safe reset, the offending combination may instead be unreachable. Test the action order, simultaneous activation, phase transitions, and any stale events that could violate that guarantee.

**Small state space for the first seed.** Start with one two-outcome breach, one two-outcome fall, and one dormant/active hazard. This yields at most eight steady-state combinations per mode phase. Test every legal combination and each warning, sweep, expiry, reset and occupancy case separately. Add a second fragile support or current state once the shared state path passes. Treat the limit as a prototype scope, with later maps bounded by their actual dependencies and profiling.

## F. Pokémon ability–environment interaction matrix

The workbook’s **Moves and Effects** tab gives the per-effect targets, requirements, counterplay, and provenance. The same move can have different environmental behavior in different titles. Field moves and spin-off construction provide evidence for what a Pokémon can do in that context. Treat the shooter’s loadout and its authored environmental payload as the authority for what can happen in a match.

| Delivered property | Evidence and boundary | Proposed shooter response |
|---|---|---|

**Eligibility choice.** Use move payload × target profile × placement role. Pokémon type can inform move selection and travel permissions such as the current Water rule. The ability to interact with cover comes from delivered work and validated geometry. Fighting-type status alone supplies no rock break. Slash and a suitable burning move can both clear an approved thorn patch through different timings and resulting states. A grab or psychic action can move the same boulder via the shared pose system. Grounded roster members always have an independent way to contest, and the important optional affordance has a general access method when its payoff warrants one.

| Target property | Valid interaction | Material or geometry constraint |
|---|---|---|
| Fibrous and exposed | Shear a thin vine, burn a dry bush, move light deadfall. | Thickness, moisture, attachment and structural role matter. A load-bearing root and a detached vine can share the same material and have different allowable states. |
| Brittle or jointed | Crush a marked stone or crystal seam, break a weak wall bay. | Use a directional seam or structural threshold. The same crystalline shape can be solid cover, an optional gate, or a fixed landmark. |
| Loose and heavy | Push a boulder, shift a slab, set a log into a rest socket. | Require enough impulse for the mass band, loose attachment, usable support and clear receiving volume. An embedded boulder can use the same mesh and a fixed profile. |
| Cold and load-bearing | Chill a thin surface, fracture a supported ice insert, thaw a cell. | A traction change preserves support. Structural ice must be seated on banks or attached surfaces and declare what lies below. |
| Permeable, conductive or supernatural | Wet a substrate, charge a designated relay, resonate with a marked crystal. | Only a specified field or linked socket can react. Give both teams access to cues and keep effect limits public. |

Prototype break time against the length of a fight and the timing of a rotation. The immediate reward for using a breach is the resulting time and exposure change after paying for approach, work, recovery, and exit. A shortcut that saves one second on paper can be slower under live fire. For a warning, measure time to recognize the cue and clear the actual swept hazard at the slowest affected speed, including wind-up, knockback and traction. Prototype one pending collapse, one independently active hazard pocket and one solid residual proxy in a test combat zone before increasing concurrency. Treat those counts as test conditions for measuring cost and readability.

## G. Technical implementation strategy

### Gameplay significance and return on cost

| Class | Player decision and counterplay | Procedural and runtime burden | Priority |

Complexity is relative for this project. Per-match budgets need measurement on the target server and client configurations.

### Authoritative state and visual simulation

- Replicate the accepted layout ID, generator/rules versions and content hash, instance and profile IDs, state/pose, state epoch and revision, authoritative start/commit tick, and timer where needed. Damage stage can replicate as a band unless exact integrity is needed for a visible interaction. Add a match snapshot or replayable state deltas for late join and reconnect. A seed alone cannot describe actions taken in the match. [TE04](https://gafferongames.com/post/snapshot_interpolation/)
- Server-authorize hits, effects, thresholds, volumes and transitions. Use event or snapshot replication with idempotent revisions and periodic reconciliation. A lost or repeated event cannot resurrect an old wall or fire two hazards. Clients may predict a hit cue and interpolate movement/VFX. Gameplay collisions, cover, pathing, hazard contact and scoring follow committed state. Cosmetic dust and shards can be locally spawned and culled.
- Establish a lag compensation policy for changing cover. For hitscan, sample shooter/target and relevant cover from a consistent time view within a bounded history. Then apply structure damage only to the matching valid lifetime and phase epoch. Choose explicitly how shots crossing a recent opening or closure adjudicate. For persistent projectiles, use the declared current-tick collision policy. Verify peeking, break timing, contested cracks and low/high latency head-to-head. [TE06](https://www.gabrielgambetta.com/lag-compensation.html)
- Bake transition outputs before acceptance. On commit, publish geometry, surface support, projectile masks, field volumes and conditional edges as one version. When a dependency is still loading, hold the current valid state and communicate the delay or cancel. Replay the authoritative events plus agreed cosmetic seeds when needed for presentation.
- Set explicit limits per zone and match on live gameplay bodies, simultaneously active volumes, changed navigation cells, replicated deltas, and cascades. Profile server simulation time and client frame time at median and tail percentiles, bytes per event and snapshot, join/resync time, and rejected/delayed transitions. Use a conservative fixed proxy or defer a new legal action when a budget is reached. Never drop an already authoritative support or obstacle update to save a frame. Measure on stress seeds with synchronized attacks, collapse, reconnect and overtime.

**Minimum playable destruction vocabulary.** Implement ST02, ST03 and ST04 or ST05 over a single state handler. Use a persistent remainder for breakable cover, an optional door-sized breach, and a final rest collider for one directed fall. Asset scope is one small brittle prop, one weak-panel shape fitted to B12, and one standing/rest pair. Add ST06 using the same handler when existing hazard volumes can support it. This gives three tactical decisions with two geometric operations, and a field operation for the next habitat-specific milestone.

**Extensions with a distinct payoff.** A finite dam or weir can reproduce a Seafoam-style decision if it switches one contained reach. A snow slab or unstable cliff can threaten a signaled apron without full avalanche or rubble simulation. A storm-driven river, spread fire, deforming glacier, or pressure rupture becomes a separate simulation feature when players need to reason about propagation. In the first competitive maps, persistent support and authored outcomes make the affected area and counterplay legible.

**Project sequence.** First prove the vertical slice on a fixed version of Shrine Gorge or Cinder Crater. A side parapet or sacrificial cooled rock uses the existing geometry, and a breach can reuse the planned F07 prototype. Use one optional opening and one fixed patch or fall across the two recipes before enabling placement across many seeds. Validate the current liquid and fall rules first where a new state removes support. PvE proves geometry and rules. Side-swapped versus runs and a networked match establish the next release gate. For each feature, compare a paired static layout to isolate the difference, then vary the seed, specialist access and affected role. Record time to break, new route usage, survival and retake after changes, correct state identification, and worst-case simulation and replication.

## I. Updated procedural generation architecture

The existing environment and gameplay graph separation stays the foundation. Extend their contracts at the generator’s points of contact. Persistent geometry and gameplay remain independently defined. Each interactive placement links a supported environmental component to a certified set of local state outcomes.

| Existing stage or responsibility | Extension and data relationships | Validate before proceeding |
|---|---|---|
| 1. Resolve identity, roster and mode | Recipe chooses interaction roles and allowable state profiles. The geometry family keeps its original ID. The mode supplies phase clocks, objective protection and baseline requirements. | Reject incompatible interactions on protected anchors or unsupported geometry. Declare traversal, hazard and reset rules. |
| 2. Sketch environment fields and topology | Add safe route, support, retreat, occupancy and sightline reservations to planned gameplay graph. | Transition resolver | Integrity, state/timers, conflict resolution, causal rules and commit revision. | Requests clearance and mode checks. Publishes approved state deltas to all consumers. |
| Geometry, physics and presentation | State-specific contact and combat proxies, optional scripted/rigid motion, and local visual/audio cues. | Authoritative movement/shot/field data plus cosmetic events. Visual debris does not own route edges. |
| Navigation, topology and hazards | Current per-profile edges, support, threat, exposure and recovery logic. | Map revision, changed region and link masks. AI navigation requests and authoritative contact samples. |
| Replication and replay | Sequenced state deltas and match snapshots, epochs and join state. | Layout ID, content version, transition ticks, states/poses and any timing/causal context required to restore them. |
| Placement and validation | Eligibility rules, dependencies, state certificates and repairs. | Produces accepted layout and allowed transitions. Logs failing state/sequence, geometry and profiles for rework. |

The game mode owns objective activation and scoring. Its protected volumes are constraints for component placement and transition guards. Moving an objective with a collapsing structure would be a different mode rule, with its own support and state graph. Map load validates layout/profile identity. Runtime checks protect the allowed finite state transitions. Release testing certifies what can happen in play, including mode and roster updates.

## Worked environments

All five examples adapt the earlier recipes. Their listed action sequences are proposed gameplay, with location sources preserved in the original specification. Some sites may use one enabled interaction when a seed cannot support the whole example.

### 1. Haunted cemetery inside wild forest

**Original recipe.** T02/T26, with optional T27 crypt. Reuse A14 markers, A15 columns, A16 walls, A18 memorial anchor, B12 crypt aperture, C02/C10 and F02/F07.

**Transitions.** Two weathered A14 markers use ST02 and leave low stumps. A separate A15 post falls into a prepared A02 rubble proxy (ST04). One loose marker can move between two contained sockets (ST05) to trade a peek along the wall for shelter at the crypt entrance. An A16 insert in B12 uses ST03 to open the optional crypt shortcut after slow shared work or faster crush. The focal memorial, both paths and the walls that screen their entrances are fixed.

**Tactics and certification.** The lower wall and upper contour approaches still offer independent angles and retreat. The crypt branch has two exits and the breach is audible. Test the gravestone removals, displaced marker, fallen post and breach together. If the crypt aperture looks directly into the upper approach after all smaller cover is gone, install a permanent bend or rotate the opening. Use baked swaps and one swept post motion. Reset solids between rounds. [Old Cemetery](https://bulbapedia.bulbagarden.net/wiki/Old_Cemetery) · [Memorial Hill](https://bulbapedia.bulbagarden.net/wiki/Memorial_Hill)

### 2. Volcanic mountain with cliffs, caves and vents

**Original recipe.** T07/T11/T21. Reuse A01/A04 cooled rock and pendants, B05 cliff/ledge, B12 cave mouth, B19 vent, C06/C07 and E03/F08.

**Transitions.** A sacrificial cooled-rock insert opens an optional bypass (ST03). A marked ceiling pendant gives a short warning and falls to a certified recess (ST04). Its group can trigger one vent pulse (ST09/ST14), using a visible steam/exposure field and expiry. A wider cooled-rim blockout and cave ascent both keep hard cover and independent ingress. The lava channel, crater and structural roof stay supported.

**Tactics and certification.** Players can pre-open the bypass or trigger the pulse to delay opponents crossing a side recess. Align the fall into a pre-carved talus socket and keep the vent/hazard union away from both required approaches and the attack/defense checkpoint. Test escape time from the slowest profile after knockback and concurrent vents. Actors who enter the exposed lava sample actual contact and use the project’s lava rule. Use finite volumes and a scripted fall. An optional *Pokopia*-inspired crust pocket is a later state-swap variant. [Mt. Chimney](https://bulbapedia.bulbagarden.net/wiki/Mt._Chimney) · [Fiery Path](https://bulbapedia.bulbagarden.net/wiki/Fiery_Path) · [Firespit Island](https://bulbapedia.bulbagarden.net/wiki/Firespit_Island)

### 3. Tropical island jungle and waterfall

**Original recipe.** T03/T12/T15 with T16 headland. Reuse A06 trunk, A07 roots, A08 logs, A09 lianas, A10 understory, C02/C03/C14, E04 and F02/F05.

**Transitions.** A small mature tree has a visible fall direction toward a dry shelf. ST04 turns standing vertical cover into a low A08 proxy across a side gully or beside a fighting pocket, depending on the approved slot. Selected brush uses ST10 with optional timed regrowth. An independent loose log uses ST05 along a short track above the bank. Felling, growth, and log movement share a group if their sweeps overlap.

**Tactics and certification.** Felling changes head-height exposure and can open a short rotation. Brush removal exposes a flank along the dry causeway during escort. An upstream bridge and a sheltered dry waterfall route remain viable. Keep protected roots, canopy identity, stream outlet and payload sweep clear. Check the highest flying perch after felling, landing on a resting log, and whether that log provides an unintended spawn line. Use a scripted fall and placement anchors. Regrowth of concealment uses a field/visual swap. [Lush Jungle](https://bulbapedia.bulbagarden.net/wiki/Lush_Jungle) · [Founja Jungle](https://bulbapedia.bulbagarden.net/wiki/Founja_Jungle)

### 4. Frozen mountain lake and ancient ruins

**Original recipe.** T07/T10/T13/T22/T28. Reuse B08 basin, B16 ice support, A23 brittle tile, C08 margins, E01 water, E02 traction and F03/F07/F08.

**Transitions.** Two designated ice cells form an optional mid-route shortcut. Stress, impact or heat uses ST07 to crack, warn, then open one cell. A brittle floor in the cave can instead reveal a lower supported landing. An E02 patch can switch traction (ST06) independently of support. Each water cell has an exit to a dry bank. An approved chill action can restore a cell once occupied/swept volume is clear. Use a single brittle cell in the first test.

**Tactics and certification.** Opponents can deny a quick crossing or catch someone at a predictable exit. Safe route pairs run along a dry shore and through a screened ridge/gallery. Test both ice cells broken, each break under a slow grounded body, swimmers’ early exit shot angles, slip plus knockback, and the effect of simultaneous thaw and refreeze. Keep lethal voids away from unavoidable runout. Use finite support swaps and the existing liquid policy. Round reset is the initial restoration policy. [Avalugg’s Legacy](https://bulbapedia.bulbagarden.net/wiki/Avalugg%27s_Legacy) · [Snowpoint Temple](https://bulbapedia.bulbagarden.net/wiki/Snowpoint_Temple) · [Icefall Cave traversal](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_FireRed_and_LeafGreen/Part_18)

### 5. Legendary sanctuary integrated into a mountain

**Original recipe.** T07/T20/T28, with an optional T23 or T33 overlay. Reuse A15 columns, A16 wall bays, A18 platform, A19 motifs, B11 terraces, C11 shrine and optional C09 crystal growth.

**Transitions.** A sacrificial outer column falls to a low rubble proxy (ST04). A side bay’s crystal insert uses ST03 or ST12 to retract into a visible receiver and open an upper balcony loop. A shared interaction point or a suitable move can trigger it. An optional temporary cover panel uses ST08 in a recess that cannot seal the colonnade. The shrine axis, support columns and objective platform are protected. A coherent alternate visual field can accompany the switch, with the first recipe using the normal gravity frame.

**Tactics and certification.** The external switchback and cave gallery reach opposite contest angles with stable cover. The balcony creates a timing and rotation option. A grounded player can respond from the terrace and exit behind a fixed occluder. Test the aperture, post and created cover together with maximum jump/flight reach. If the balcony sees both entrances, restrict its sightline or remove its elevated firing position. A separate optional gravity experiment would add F09 movement and shot semantics. [Mt. Coronet](https://bulbapedia.bulbagarden.net/wiki/Mount_Coronet) · [Spear Pillar](https://bulbapedia.bulbagarden.net/wiki/Spear_Pillar) · [Area Zero Underdepths](https://bulbapedia.bulbagarden.net/wiki/Area_Zero_Underdepths)

### Mixed-zone stress case

In the original wooded gorge and tidal cave hybrid (T02/T08/T09/T16/T18), a moved plug can switch one lower current. The treefall slot can alter only the upper shelf’s cover. If the high-tide state floods the lower outlet when the plug is in its second pose, that state must still provide a safe reverse route or disable that pose under a public interlock. Test if a rooted tree, crystal gate or moving boulder can be reached while the water rises. Reserve the upper dry gallery and the fixed coast bypass for the baseline, then validate whether the treefall exposes both under a rim firing angle. Keep the moving objective on the original dry shelf. [Shoal Cave](https://bulbapedia.bulbagarden.net/wiki/Shoal_Cave) · [Seafoam Islands](https://bulbapedia.bulbagarden.net/wiki/Seafoam_Islands)

## Conclusion

Add interaction profiles and protected placement roles to existing catalogue entries. Add named transitions and permitted outcome geometry to R01–R33 through R34–R43. Bind those outcomes to F02, F03, F04, F07, F08 and F09 wherever the change affects combat, traversal or exposure. Reuse the current environment and gameplay graphs, adding explicit dynamic edges and threat changes to the planned graph and checking them against realized geometry. Persist accepted per-seed state profiles and make their changes authoritative in the match.

Prototype a breakable prop, one optional breach and one directed fall before investing in simulation. Their state and pose changes establish the reusable runtime and placement contracts. Add a local field switch for ice, current, steam or growth once the occupied transition and hazard checks pass. Whole terrain deformation and multi-frame physics require separate evidence of value and a larger validation budget.
